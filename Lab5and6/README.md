# Lab05 Layouts

This folder follows the requested structure:

- `index.html`: entry point that links to the major sections.
- `styles/`: contains scoped CSS files for each layout technique (base, display, float, position, flexbox, grid, media queries, responsive helpers, utilities).
- `layouts/`: curated layout demos (magazine float, holy grail comparison, dashboard grid, portfolio mix, responsive landing plus breakpoints, dark-mode/media queries, flex cards, flexible form, grid gallery, product grid, responsive data).
- `exercises/`: focused practice pages covering display, float, position, flexbox, grid, and media query topics.
- `archive/`: older drafts and extra experiments (moved here to keep the main folders clean).

Open `index.html` to navigate between layouts and exercises.
