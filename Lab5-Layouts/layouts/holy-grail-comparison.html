Holy Grail Layout

1. Float-based (with media queries)

Float the nav and aside, let main fill the gap, then add clearfix so the layout stays contained. Media queries remove floats on smaller screens.

Floats require clearfix and manual margins; responsive behavior requires turning the floats off and letting each section stack.

2. Flexbox (mobile-first)

A column-based flex container stacks nav, main, and aside naturally; reorder or adjust direction for wider screens using flex properties.

Flexbox keeps everything aligned and is easier to tweak for mobile-first transitions compared to floats.

3. CSS Grid (responsive areas)

Define explicit grid areas for nav, main, and aside; media queries adjust the grid template so the single-column mobile view just reorders areas.
